## Project Overview
This Final Year Project (FYP) focuses on studying, converting, and validating subband adaptive filtering algorithms—originally developed in MATLAB—into clean, modularized Python implementations. The project evaluates full-band vs. subband adaptive filter structures in acoustic signal processing scenarios such as noise cancellation and acoustic echo cancellation (AEC).
